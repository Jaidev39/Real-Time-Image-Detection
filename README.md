# Real-Time Image Detection

A webcam-based browser computer-vision prototype that detects objects in real time.

## Overview

The project captures webcam video, runs client-side object detection, and displays detected labels, confidence values, bounding boxes, and the number of detected objects.

## Tech
- JavaScript
- p5.js
- ml5.js
- COCO-SSD
- Browser webcam APIs

## Status
Educational computer-vision prototype.
